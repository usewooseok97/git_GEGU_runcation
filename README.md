# 1만 시간의 법칙 계산기

"연습은 어제의 당신보다 당신을 더 낫게 만든다."

## 프로젝트 소개

1만 시간의 법칙을 기반으로 사용자가 원하는 분야의 전문가가 되기 위해 필요한 훈련 일수를 계산해주는 인터랙티브 웹 애플리케이션입니다.

## 주요 기능

- **목표 설정**: 전문가가 되고 싶은 분야 입력
- **일일 훈련 시간 입력**: 하루에 훈련할 수 있는 시간 설정
- **자동 계산**: 1만 시간 달성을 위해 필요한 일수 자동 계산
- **응원 모달**: 훈련하러 가기 버튼 클릭 시 응원 메시지 표시
- **반응형 디자인**: 모바일 및 데스크탑 환경 지원

## 기술 스택

- **HTML5**: 시맨틱 마크업
- **CSS3**:
  - CSS Variables를 활용한 테마 관리
  - Flexbox 레이아웃
  - Media Query를 활용한 반응형 디자인
- **JavaScript (Vanilla)**:
  - Dialog API를 활용한 모달 구현
  - Event Listener를 통한 인터랙션 처리

## 주요 코드 설명

### 1. 입력 폼 (index.html:38-61)

사용자로부터 목표 분야와 일일 훈련 시간을 입력받는 폼입니다.

```html
<form action="" method="get">
  <input type="text" id="type" placeholder="예) 프로그래밍">
  <input type="number" id="time" placeholder="예) 5시간">
</form>
```

### 2. 계산 결과 표시 (index.html:68-80)

입력받은 값을 기반으로 계산된 결과를 동적으로 표시합니다.

### 3. 모달 기능 (index.html:110-140)

Dialog API를 사용하여 응원 메시지 모달을 구현했습니다.

- `showModal()`: 모달 열기 및 backdrop 생성
- `close()`: 모달 닫기
- 배경 클릭 시 모달 자동 닫기

### 4. 스타일링

**CSS Variables (css/일만시간.css:3-8)**
```css
:root {
  --background-color: #5b2386;
  --bacground-button: #fcee21;
}
```

**반응형 디자인 (css/일만시간.css:143-161, 348-380)**
- 모바일: 세로 레이아웃
- 데스크탑 (768px 이상): 가로 레이아웃, 확대된 폰트

## 디자인 특징

- **컬러 팔레트**: 보라색(#5b2386) 배경에 노란색(#fcee21) 강조
- **폰트**: Gmarket Sans 웹 폰트 사용
- **접근성**:
  - `sr-only` 클래스를 통한 스크린 리더 지원
  - 시맨틱 HTML 태그 활용
  - ARIA 레이블 적용

## 사용 방법

1. 전문가가 되고 싶은 분야를 입력합니다.
2. 하루에 훈련할 시간을 입력합니다.
3. "나는 며칠 동안 훈련을 해야 1만 시간이 될까?" 버튼을 클릭합니다.
4. 계산된 결과를 확인합니다.
5. "훈련하러 가기 GO! GO!" 버튼을 클릭하여 응원 메시지를 확인합니다.
